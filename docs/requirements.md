# Requirements

The authoritative requirements baseline is:

./requirements-baseline.md

It contains:

- acceptance criteria;
- assumptions;
- exclusions;
- design choices;
- open questions;
- task-level Definition of Done;
- release-level Definition of Done.

Do not introduce requirements that are not present in the baseline.

When executing a WBS task, use only the acceptance criteria linked from:

- `docs/wbs.md`;
- `docs/active-task.md`;
- `docs/requirements-baseline.md`.
